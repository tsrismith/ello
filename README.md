# Ello

A study dashboard for Obsidian. It reads your courses from Canvas, tracks your tests and how ready you are, and helps you build and refine a mind map for each course.

## Install (about 5 minutes)

1. **Install [Obsidian](https://obsidian.md)** and **[Claude Code](https://claude.com/claude-code)**. Open Claude Code once in Terminal and sign in with your Claude account. Ello's AI runs through it, on your own account.
2. **Download `Ello-Starter-<version>.zip`** from the [latest release](https://github.com/tsrismith/ello/releases/latest) and unzip it somewhere you'll keep it (Documents is fine).
3. In Obsidian: **Open folder as vault** → choose the `Ello Starter` folder.
4. When Obsidian asks about the vault's plugins, choose **Trust author and enable plugins**.
5. Click the **elephant icon** in the left ribbon and follow the setup.

### Canvas token

In Canvas: **Account → Settings → + New Access Token**. Give it any name, copy it, and paste it into Ello's setup. It stays on your computer and Ello only uses it to read your courses.

### Optional

- **Anki** with the **AnkiConnect** add-on (Tools → Add-ons → Get Add-ons → code `2055492159`) for flashcard and memory scores.
- **LearnHarness** for tutoring sessions; Ello reads them for understanding scores.
- **Google Calendar**: connect it in your Claude account (claude.ai → Settings → Connectors), then turn it on in Ello's settings for class times.

## Updates

Ello updates itself when you open Obsidian (through the BRAT plugin that comes with the starter vault). Nothing to do.

## Settings

⌘P → **Ello: Open settings**, or Obsidian Settings → Community plugins → Ello.
